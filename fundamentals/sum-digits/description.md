Write a function `sum_digits(n: int) -> int` that takes a non-negative integer `n` and returns the sum of its decimal digits.

For example:
- `sum_digits(123)` → `6`
- `sum_digits(0)` → `0`
- `sum_digits(905)` → `14`

_Hint: use the remainder operator (`%`) and integer division (`//`) to peel off one digit at a time from the right._
